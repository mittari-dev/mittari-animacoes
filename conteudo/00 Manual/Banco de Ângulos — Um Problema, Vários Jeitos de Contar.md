# 🎯 Banco de Ângulos — Um Problema, Vários Jeitos de Contar

← [[../Hub de Conteúdo|Hub de Conteúdo]] · [[Siglas e Convenções]] · Dores do mercado: [[../../16 Distribuição/03 ICP e Mercado/Kalli — Mercado e Segmentos|Kalli — Mercado e Segmentos]]

> **Pedido do fundador em 06/10:** *"a gente vai anotando esses ângulos diferentes para falar de um mesmo problema."*
>
> **Por que existe:** o problema da Kalli é um só (o corretor não consegue atender bem todo cliente que chega), mas contado sempre do mesmo jeito ele cansa. Em 06/10 o fundador chamou o ângulo da noite e do fim de semana de *"chato, repetitivo e monótono: o corretor já vive isso"*. **Um ângulo bom mostra algo que o corretor ainda não tinha imaginado**, não o que ele já sofre todo dia.

## As regras

| | |
|---|---|
| **Um ângulo por peça** | Vídeo, carrossel, post ou mensagem. Dois ângulos na mesma peça são duas peças |
| **Todo ângulo tem uma função real por trás** | Se a Kalli não faz aquilo **hoje**, o ângulo fica no banco até fazer. Conferir com o chat de código antes de produzir |
| **Dor e desejo na mesma linha** | O ângulo diz o que dói **e** o que o corretor passa a querer. Só dor é reclamação; só desejo é promessa |
| **Registrar onde foi usado** | Na coluna *Usado em*. É ela que mostra quando um ângulo gastou |
| **Ângulo gasto não abre peça** | Pode aparecer no meio de uma peça, mas não na primeira linha nem no primeiro segundo |
| **Sem a palavra "lead"** | O corretor fala "cliente" (dois não entenderam em 06/10) |

**Estados:** 🟢 em uso · 🎯 escolhido para uma peça · 📦 no banco · ⚠️ gasto · 🔒 espera o produto

## Como um ângulo novo entra

1. **Vem do campo**: uma fala de corretor, uma objeção, uma coisa que o fundador viu. A fala literal entra entre aspas
2. Ganha uma linha aqui com **dor, desejo e função real**
3. Fica 📦 no banco até ser escolhido para uma peça
4. Quando uma peça usa, a coluna *Usado em* ganha o link
