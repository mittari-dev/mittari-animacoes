# 🔻 E06 — O Funil que Você Nunca Contou

← [[../05 Ideias/Leva 03 — Série Você Não Viu (11-11)|Leva 03]] · Vídeo: `videos/2026-11-11_leva-03_serie-consciencia/2026-11-11_kalli_o-funil-que-voce-nunca-contou/`

| | |
|---|---|
| **Ideia em uma frase** | Todo corretor sabe quanto vendeu; quase nenhum conta conversas, respostas no dia e visitas, e é nesses vãos que a venda some |
| **O que o corretor não tinha visto** | Que ele mede o fim do caminho e não o caminho |
| **Série** | Você não viu (consciência) |
| **A porta** | Fazer a conta e comentar quantas visitas marcou |
| **O que a porta exige de nós** | Responder os comentários; número baixo de visitas é motivo para chamar no direct |
